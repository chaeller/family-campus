# ADR-0007: Progress counts finished sets

- **Status:** Accepted
- **Date:** 2026-11-22

## Context

Opening a tile or answering one question is not learning progress. Children
should see a clear, honest measure.

## Decision

A tile's progress is the number of its sets finished at least once, with the
best result per set and the number of runs. Opening a page or leaving a set
half-way counts nothing; single answers still go into the statistics and
the revision box.

## Consequences

+ "3 of 5 sets · Ø 85 %" is easy to understand and hard to fake.
− A long set left half-way shows no progress.

## Alternatives considered

- **Time spent or pages opened:** says little about learning.
